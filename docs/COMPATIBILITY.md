# Compatibility status

| Area | Status |
|---|---|
| Xbox One x86-64 CPU | Not implemented |
| CPU instruction decoder/executor | Not implemented |
| Guest memory/MMU model | Not implemented |
| Xbox One OS/services | Not implemented |
| AMD GCN graphics | Not implemented |
| Xbox 360 Xenos renderer | Not implemented |
| Audio/input/storage | Not implemented |
| Xbox 360 boot / XEX | Not implemented |
| Commercial game compatibility | Not tested; none claimed |

The Xbox One and Xbox 360 architectures differ substantially. A successful host build or unit test does not demonstrate game compatibility.
